# The 20-point audit checklist

Run against an agent folder. Each line is present or a genuine gap. Adapted from Dryxio (@dryxio), whose list matches Cooper Simson's scaffold independently.

1. One main folder holding all projects. 2. A `brain/` folder. 3. `CLAUDE.md` at the top with all rules and preferences. 4. A model-routing habit to save tokens. 5. The 5 core context files: business, offer, customers, voice, goals. 6. A `memory/` folder. 7. An index file. 8. `tools.md`. 9. Per-project folders. 10. One context file per project, standard filename. 11. (optional) Obsidian as a reading view. 12. Versioning or backup (GitHub if you use git). 13. `now.md` for short-term memory. 14. (optional) Notion for open tasks. 15. A rules file so projects do not bleed together. 16. A `skills/` folder. 17. A `workflows/` folder. 18. A `scripts/` folder. 19. `.env` for keys and passwords. 20. `.gitignore` listing `.env`, set up before the first push.

Items 11 and 14 are optional viewers, not infrastructure. Same rule as everywhere: a line earns its place when there is real content for it. Do not scaffold an empty file to tick a box.
