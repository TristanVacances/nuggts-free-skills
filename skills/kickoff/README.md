# Kickoff

**The only command you need to remember.** You have dozens of skills installed and can't remember which does what. `/kickoff` picks them for you.

**What it does:** type `/kickoff` and say what you want ("a launch email for my workshop"). It:
1. reads your context (or asks 3 questions once and saves the answers)
2. picks the right installed skills and tells you why
3. does the work
4. runs a separate fresh-eyes review
5. hands you the fixed version

It also leaves a note for next session, so you never start from zero.

**Before:** you open Claude, type a vague request, get a generic answer, and spend 20 minutes steering.
**After:** you describe the outcome once; the right skills fire and you get a reviewed draft.
