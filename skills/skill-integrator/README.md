# Skill Integrator

**Found a cool skill? Check it before it turns your setup into a junk drawer.** Vets the new thing, maps what it overlaps with in your current stack, and changes only what needs changing.

**What it does:** paste a GitHub link, zip, SKILL.md, plugin name or even a method from a video. It:
1. **Vets it:** prompt-injection text, data sent to outside servers, download-and-run scripts, credential reads, browser takeover, unverified claims.
2. **Maps it against your stack:** each capability comes out as new, duplicate, upgrade or conflict.
3. **Gives one verdict:** install as is, install trimmed, fold the good part into a skill you already have, or skip.
4. **Folds surgically:** anchored edits that rewrite the paragraph the new idea improves (no "appendix" pile-up), with the target of a net word count of zero.
5. **Shows you the full plan first.** Nothing is installed or edited until you say yes. Then it backs up, applies, and tests the triggers.

**Before:** you install a fourth "copywriting" skill. Now three of them fire on "write a landing page" and give you three different rules about headlines.
**After:** "Skip installing. Your copywriting skill already covers 80% of it. The one new idea (a headline test) is folded into its headline step: +1 line, −2 outdated lines. Here's the diff, OK?"
