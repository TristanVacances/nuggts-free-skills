Concrete shape (Zach's "model-proof system"): a folder of plain-text notes with
- `CLAUDE.md` — operating rules / who the AI is,
- `USER.md` — background, voice, preferences,
- `MEMORY.md` — persistent facts across sessions,
- numbered folders — `00-Inbox/` (raw capture), `01-Maps/` (navigation hubs),
  `02-Reference/`, `03-Projects/`, `03-Templates/`, `04-Archive/`,
- **wikilinks** — `[[double brackets]]` on every person/project/topic that has its
  own note, so the structure itself is the index the model walks.

Point Claude Code (or similar) at the folder; the files are the system, the model
is interchangeable. Same doctrine as above, aimed at *time*: structure survives
model churn.
